## 本轮发现并修复

1. 错误密码在 UI 被显示为泛化“操作失败”。ChatServer 的 ErrPassword 明确为 20001 / PasswordError；在认证边界映射为“账号或密码错误”，未知错误仍执行安全过滤。新增测试先失败，再修复，真实浏览器复验中文提示。
2. 已解散群聊天仍显示输入、附件和录音入口。权限 Hook 原来只处理禁言。补充解散、不可用状态、非成员；第一次权限未确认时也不开放发送，权限请求失败时关闭发送并保留重试，成功后恢复。
3. 权限请求抛出的 SDK 路径诊断被直接用于页面文案。改用统一 errorMessage 过滤。
4. 聊天头拨号和通话记录“再次呼叫”共用权限检查；限制提示在当前页面处理，不写入全局会话列表错误。
