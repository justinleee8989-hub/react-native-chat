# 启动承接与首屏缓存

保留现有界面、业务和 LegendList；仅独立 QA 验收，录音/视频不测，不推送。

1. 应用导航：有内存记录时不等待历史刷新；无记录保留预加载就绪门槛。按下预取复用现有并发合并。测试未返回请求、账号切换与取消。
2. 首页快照：通过 infrastructure/storage 保存小型、版本化、按用户和服务器隔离的会话展示快照。恢复期间只读展示，不能当作已认证 session，不能触发业务操作；认证后作为首屏数据，实时刷新校正。退出清理，损坏/缺失不阻断登录。使用现有存储，不引入新原生依赖。
3. 内存容量：现有 runtime.messages 唯一数据源，最多保留50个普通会话、非活动会话最近30条；活动会话/待发送或失败消息保护，裁剪后重置分页结束标记。测试分页与账号隔离。
4. 启动页面：复用产品色板、聊天标识及 RN 原语；浅/深色原生图与RN展示协调，不强制停留。登录恢复有快照时使用只读快照过渡，错误可回到既有恢复界面。启动图仅撑到RN首个有效布局，不等待网络。
5. 验收：业务/UI/类型/lint/SDK build（如SDK改动）、Android Release，PC/H5实测，独立QA冷启动/重进/分页；记录实际边界。
