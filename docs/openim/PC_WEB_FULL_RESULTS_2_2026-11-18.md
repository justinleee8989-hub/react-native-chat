## 明确不通过项

### A7：重复登录缺少旧端提示

- 步骤：QA A 在新 Chrome 标签登录；观察旧 QA A 标签。
- 预期：旧端显示明确的重复登录/被踢下线提示，再进入登录页。
- 实际：旧标签直接进入 `/auth/login`，等待后仍没有明确原因提示。
- 影响：用户无法判断是登录过期、网络异常还是被另一端挤下线。

### C3：不存在的用户 ID 可进入伪会话

- 步骤：新建会话，输入不存在的 ID `9999999999`。
- 预期：提示用户不存在，禁止创建会话。
- 实际：进入 `/chats/si_6121886020_9999999999`，页面看起来像可用的单聊。
- 影响：可能产生无效会话、误发送和错误的本地缓存数据。
