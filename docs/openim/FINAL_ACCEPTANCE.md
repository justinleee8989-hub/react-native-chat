## 实际修复

搜索不存在的联系人原来直接显示 OpenIM 的英文 Go 调用栈和内部文件路径。新增统一错误提示转换，在页面任务与聊天状态提示中将已知用户/权限/连接错误转为中文，未知内部异常使用通用重试提示，保留应用自身的中文校验。先复现两项失败，再修复通过；H5 重新加载后复测为“未找到用户，请检查用户 ID”。

源码热更新期间 SDK 曾重复初始化导致临时连接失败；完整重新加载后恢复。Chrome 扩展 injected.js 的独立错误浮层单独记录，不作为应用功能失败。
