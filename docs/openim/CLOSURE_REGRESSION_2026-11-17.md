## 本轮实际功能覆盖

- PC/H5 浏览器走查覆盖认证入口、会话/新建会话、联系人/好友请求、个人资料与设置、群列表/申请/加入/资料/管理/成员/邀请、搜索、媒体、归档、已读成员、通话记录等页面及相应实际 QA 状态。
- 消息流程覆盖真实 QA 账号间发送与搜索定位、编辑/回复/转发/回应元数据、已读成员查询、撤回/删除后的消失检查；附件媒体类型入口与刷新/返回路径也有实际检查。QA 数据量和状态与原型种子数据不同，结果以对应真实状态为准。
- 独立 API 测试覆盖 API 注册与登录、资料更新、好友申请/接受、群创建/邀请/群消息及消息编辑/回应/已读/搜索/撤回等流程。第三个 QA 账号 C 的重置与改密在 API 层验证；这些 API 结果不代表浏览器认证 UI 的逐步流程已全部验证。浏览器层仅对实际打开并操作的页面和状态作结论，不以接口成功推断页面通过。
- 本轮 QA 认证采用独立账号；A/B 浏览器由父代理操作，避免因重复登录造成会话踢出。后端 API 回归期间使用对应业务令牌类型，没有复用失效的 A/B 浏览器会话。
- 邮箱回归使用 v17 的自邮箱隔离配置验证，范围是本地 QA 验证路径；不据此宣称外部真实邮件投递或生产邮箱服务通过。
