# PC 端与 Web 端复测说明（第三轮）— 2026-11-18

第二轮结果见 [PC_WEB_FULL_RESULTS_2_2026-11-18.md](PC_WEB_FULL_RESULTS_2_2026-11-18.md)。本轮修复第二轮确认的两个缺陷和两个质量问题，复测这四项，并复现两个还没确定原因的问题。环境同第二轮：真实桌面 Chrome + DevTools；Safari 一项用 macOS Safari。

测完后填写 `PC_WEB_RETEST_3_RESULTS_2026-11-18.md`，证据放到 `docs/openim/evidence/2026-11-18-pc-web-retest-3/`，提交并推送到 `perf`。第三节列出的有状态操作仍在第二轮授权范围内。

## 一、本轮修复

| 问题 | 原因 | 改动 |
|---|---|---|
| **A7** 同账号在别处登录后，旧标签直接回到登录页，没有任何说明 | 被挤下线时其实设置了提示，但 Web 退出登录会整页刷新，内存里的提示在刷新后丢失；而且被挤下线、令牌过期、令牌失效三种情况共用"登录已失效" | 被挤下线时提示"该账号已在其他设备或浏览器标签页登录，当前登录已退出。"，令牌过期或失效仍提示"登录已失效，请重新登录"。退出前把原因存进当前标签页，刷新后的登录页显示一次就清除；重新登录成功后也会清除 |
| **C3** 发起聊天时输入不存在的 ID，会进入一个看起来正常的单聊 | 页面直接让 SDK 打开会话，SDK 对任意 ID 都会在本地建会话 | 打开前先查询用户（和添加好友页同一个查询）；查不到时提示"没有找到该用户，请检查用户 ID 是否完整、正确。"，不进入会话 |
| **H3** 消息通知开关打开后，无障碍信息里的值仍是 0 | 开关只设置了 `accessibilityState`，当前版本的 react-native-web 需要 `aria-*` 属性 | 开关同时提供 `aria-checked` 和 `aria-disabled` |
| **J6** 控制台警告 `Animated: useNativeDriver is not supported` | "正在输入"动画在 Web 上也请求原生驱动 | 只在原生端使用原生驱动 |

**用户手动测试反馈：PC 上除了会话列表和会话之间切换，其他页面点击和切换都会跳动，像整个页面刷新。**

| 原因 | 改动 |
|---|---|
| PC 上已经打开一个详情（好友资料、群聊、设置等）时，再点中间列表的另一项，会先把导航重置回分区首页（右侧闪出"选择…"空白页），再推入新详情。外壳（左侧导航栏、中间列表、右侧详情）因此被卸载后重新挂载，看起来就像整页刷新。只有会话切换会话时直接原地替换，所以会话不跳 | 已有详情打开时，**任何列表项**都和会话一样原地替换。详情栈有多层时（如群资料 → 群管理 → 成员），先退回第一层再替换，两步在同一次点击里完成，不会先画出空白页 |
| 外壳重新挂载后，通讯录和我的从空状态重新加载，先显示骨架再换成内容。会话列表的数据在全局状态里，所以不受影响 | 通讯录和我的记住当前账号上一次加载的数据。重新挂载时直接显示，后台静默刷新（刷新时只有浮层加载圈）。换账号后不会读到上一个账号的数据 |

另外两类控制台警告（`[legend-list] recycleItems was not provided` / `List height is 0`、焦点元素被 `aria-hidden` 包含）这轮没有改，原因待第三节第 5 项确认。

## 三、复现与确认

| 编号 | 内容 | 要记录的 |
|---|---|---|
| 1 | **清空好友备注**：QA A 打开 QA C 的资料 → 更多 → 设置备注，先改成 `QA 备注测试`，刷新确认已保存；再把输入框清空、确定；刷新后再看 | 刷新后备注是"未设置"还是旧值。DevTools → Network 里找到清空这一步发出的请求（Web SDK 走 WebSocket 时在 WS 消息里），截取请求和响应（**去掉 token**）。测完把备注恢复为未设置 |
| 2 | **Safari 登录**：macOS Safari 打开登录页，先清空账号和密码框里的自动填充内容，再手动输入 QA A 的账号和密码登录 | 能否登录。如果仍提示账号或密码错误，换成 Chrome 在同一时间用同样的输入登录一次，对比结果；在 Safari 的 Web 检查器里截取登录请求（**去掉密码和 token**） |
| 3 | QA C 修改密码（第二轮未取得证据） | 修改成功提示 → 自动退出 → 新密码可以登录、旧密码不能登录。新密码只交给用户，不写进仓库 |
| 4 | 上传中刷新（D15） | 用 DevTools 把网络限速到 Slow 3G，上传一个 2 MB 文件，进度出现后立即刷新；记录刷新后是否看到待办附件，以及继续和取消是否可用。测完恢复 No throttling |
| 5 | 控制台剩余警告 | 分别在 PC 布局和 390px H5 下，记录 `[legend-list] recycleItems`、`List height is 0`、`aria-hidden` 三类警告各自在**哪个页面、什么操作后**第一次出现 |
